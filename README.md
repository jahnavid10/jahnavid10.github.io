# jahnavid10.github.io

Personal CV / portfolio site for Jahnavi Dulala, served via GitHub Pages at
https://jahnavid10.github.io

## Structure

- `index.html` — page content
- `style.css` — styling (light/dark theme via CSS variables)
- `script.js` — theme toggle, mobile nav, scroll progress, reveal-on-scroll

## Updating content

Edit `index.html` directly — each section (About, Experience, Projects, Skills,
Education, Certifications, Contact) is clearly marked. No build step required;
this is a static site.

## Deploying

Push to the `main` branch, then enable GitHub Pages in the repo settings
(Settings → Pages → Source: `main` branch, `/ (root)`). The site will be live
at `https://jahnavid10.github.io` within a minute or two.
